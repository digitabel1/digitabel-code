DigitAbel Code

Skriv og kjør python på nett

v0.63

DigitAbel Code gir elever i grunnskolen et enkelt sted å skrive og kjøre egen Python-kode direkte i nettleseren – uten installasjon eller oppsett. Biblioteker som NumPy og Matplotlib følger med, slik at elevene også kan utforske beregninger, visualisering og programmering med kraftige verktøy.
Tjenesten er laget av DigitAbel.org som et supplement til de andre ressursene våre. DigitAbel Code skal være en lett tilgjengelig læringsarena – ikke en fullverdig erstatning for utviklingsmiljøer som Thonny, Visual Studio Code eller Jupyter.

Tastatursnarveier:

Ctrl + Enter → Kjør Ctrl + O → Åpne
Ctrl + S → Lagre Ctrl + Z → Angre
Ctrl + + → Zoom inn Ctrl + - → Zoom ut

DigitAbel Code er laget av digitabel.org, med hjelp av opensource-programmene pyodide og codemirror. Har du en tilbakemelding, eller ønsker å kontakte oss, gå til våre kontakt-sider. Les også vår personvernerklæring.
