DigitAbel Code

Personvernerklæring

Gjelder DigitAbel Code (Python-editoren på / og Turtle-editoren på /turtle/).

Kort oppsummert:
  • Du trenger ikke opprette konto, logge inn, eller oppgi navn eller e-post for å bruke DigitAbel Code.
  • Vi lagrer anonym bruksstatistikk (tidspunkt, type hendelse, en grov enhetstype og hvilken side) – ikke IP-adresse eller andre personlige identifikatorer.
  • Koden du skriver, temavalg og lignende lagres kun lokalt i din egen nettleser, og sendes ikke til oss – med unntak av at du selv kan velge å dele koden din via en delelenke.

Hvem er ansvarlig

DigitAbel Code driftes av DigitAbel.org, som er dataansvarlig for behandlingen beskrevet her. Har du spørsmål, gå til våre kontakt-sider.

Bruksstatistikk

For å forstå hvordan DigitAbel Code brukes, og for å kunne forbedre tjenesten, registrerer vi enkelte hendelser – som sidevisninger, at koden kjøres, og at appen installeres som PWA. For hver hendelse lagres:

  • Tidspunkt for hendelsen
  • Hvilken type hendelse det er (f.eks. sidevisning eller kodekjøring)
  • En grov enhets-/operativsystem-etikett (f.eks. «Windows», «Android», «iOS») – ikke hele nettleserens fulle identifikasjonsstreng
  • Hvilken side/del av appen hendelsen skjedde på

Vi lagrer ikke IP-adresse eller andre identifikatorer sammen med disse hendelsene, og de kan ikke kobles til en bestemt person. Loggene lagres i enkle tekstfiler på serveren (én fil per måned) og fjernes ikke automatisk.

Merk: webserveren som drifter siden kan, uavhengig av dette, føre egne tekniske tilgangslogger (f.eks. IP-adresse) som del av normal drift og sikkerhet – dette er ikke noe DigitAbel Code selv styrer eller bruker til annet enn feilsøking/sikkerhet ved behov. Se «Hosting» nedenfor for detaljer.

Lokal lagring i nettleseren

Følgende lagres kun lokalt i din nettleser (localStorage), og sendes aldri til oss:

  • Valg av lyst/mørkt tema
  • Om autofullføring er på eller av
  • Automatisk mellomlagring av koden din i hovededitoren, slik at du ikke mister arbeidet ditt ved et uhell

Denne informasjonen ligger kun på enheten du bruker, og forsvinner hvis du sletter nettleserdata for siden.

Delelenker

Hvis du bruker «del»-funksjonen, kodes koden din inn i selve nettadressen (URL-en). Dette skjer i din egen nettleser – koden lagres ikke hos oss. Alle som får lenken av deg, kan åpne og se koden, så del kun lenker du selv ønsker å dele.

Tredjepartstjenester

Siden laster noen ressurser (skrifttyper, ikoner og programvarebiblioteker som Pyodide, Skulpt og CodeMirror) fra eksterne CDN-tjenester (bl.a. Google Fonts, Cloudflare og jsDelivr). Disse tjenestene kan se IP-adressen til din nettleser når ressursene lastes, på samme måte som ved besøk på de fleste nettsider. DigitAbel Code bruker ingen analyse- eller annonseverktøy fra tredjeparter, og deler ikke opplysninger om deg med disse tjenestene.

Hosting

DigitAbel Code kjøres på servere hos vår driftsleverandør Domeneshop AS (org.nr. 930834408). Domeneshop er databehandler for oss når det gjelder hosting og domene, og fører – som del av sin normale drift og uavhengig av bruksstatistikken beskrevet over – egne tekniske logger (f.eks. web- og e-postserverlogger med IP-adresse, tidspunkt og HTTP-headere). DigitAbel Code har ikke tilgang til og bruker ikke disse loggene selv. Du finner mer informasjon i Domeneshops egen personvernerklæring, og en oversikt over deres underleverandører på domeneshop.no/suppliers. Spørsmål om den hostingrelaterte databehandlingen kan rettes til Domeneshop via domeneshop.no/contact.

Bruk i skole

DigitAbel Code kan brukes fritt av elever og lærere uten registrering. Representerer du en skole eller skoleeier og har behov for en databehandleravtale eller mer informasjon om databehandlingen, ta gjerne kontakt via kontakt-sidene våre.

Dine rettigheter

Siden vi ikke samler inn opplysninger som kan identifisere deg som person, har vi normalt ingen data å vise innsyn i, rette eller slette knyttet til deg spesifikt. Har du likevel spørsmål om personvern knyttet til DigitAbel Code, eller mener du at vi behandler opplysninger om deg i strid med regelverket, kan du kontakte oss via lenken over, eller klage til Datatilsynet.

Endringer
