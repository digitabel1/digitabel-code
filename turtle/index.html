turtle.Code

Tegn med Python Turtle

turtle.Code er en enkel editor for å lære programmering med pythons turtle-grafikk. Skriv kode i editoren til venstre, klikk Kjør, og se skilpadden tegne på tegneflaten til høyre!

Merk: TurtlEd bruker Skulpt, som støtter standard turtle-kommandoer. Noen avanserte funksjoner fra nyere Python er ikke tilgjengelige.

Tastatursnarveier:

Ctrl + Enter → Kjør kode Ctrl + S → Lagre som .py-fil Ctrl + O → Åpne .py-fil Ctrl + Z → Angre

TurtlEd er laget av digitabel.org, med hjelp av Skulpt og CodeMirror. Har du en tilbakemelding, eller ønsker å kontakte oss, gå til våre kontakt-sider. Les også vår personvernerklæring.
